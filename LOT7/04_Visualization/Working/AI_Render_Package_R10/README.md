## Use (one run per elevation)

1. Open a new chat or session in the image tool for each elevation, so the views do not influence each other.
2. Attach the images in this order:
   1. `…_1_Input_Elevation.png`: the geometry to keep exactly.
   2. `…_2_Reference_…png` (and `…_3_…` where there is one): depth and hardscape reference only.
   3. Optional: the swatches from `00_Material_References/`.
3. Paste the full text of `…_Prompt.txt`.
4. Check the result against the input elevation:
   - silhouette and roof lines;
   - number and division of the windows;
   - continuous headers;
   - railings;
   - grade line;
   - no added trees, cars or gutters.
5. Render all four views in the same tool and with the same settings, so exposure and materials match.
6. Save the selected results to `04_Visualization/Renders/R10/`. Name each one `JESB_Lot7_R10_Render_<view>.png`.
